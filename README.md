# AI Translate

Заготовка расширения для Chrome и Firefox на Vue 3, TypeScript и WXT (Vite).
Оба браузера используют Manifest V3; WXT формирует соответствующий manifest и фоновый скрипт для каждого браузера.

## Запуск

Нужны Node.js 24 LTS (24.15+) или 22 LTS (22.22.2+) и npm.

```sh
npm install
npm run dev
npm run dev:firefox
```

Команды разработки автоматически открывают выбранный браузер с расширением и обновляют его при изменениях.
Если браузер не найден, задайте путь через локальный `web-ext.config.ts` по [инструкции WXT](https://wxt.dev/guide/essentials/config/browser-startup).

## Проверка и сборка

```sh
npm run typecheck
npm test
npm run build:all
```

Отдельные сборки: `npm run build` (Chrome) и `npm run build:firefox` (Firefox).
Архивы для распространения: `npm run zip` и `npm run zip:firefox`.

### Chrome

1. Откройте `chrome://extensions` и включите режим разработчика.
2. Нажмите «Загрузить распакованное расширение».
3. Выберите папку `.output/chrome-mv3`.

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите «Загрузить временное дополнение».
3. Выберите `.output/firefox-mv3/manifest.json`.

Временное дополнение удаляется после перезапуска Firefox. Для постоянной установки потребуется подписанный пакет.
Заготовка ориентирована на Firefox 140+.

## Структура

```text
assets/main.css             Общие стили
entrypoints/background.ts   Фоновые обработчики расширения
entrypoints/popup/          Всплывающее окно на Vue
entrypoints/options/        Страница настроек на Vue
entrypoints/selection.content/ Кнопка и карточка перевода на веб-страницах
utils/settings.ts           Типы и сохранение настроек
utils/openrouter.ts         Запрос перевода к OpenRouter
wxt.config.ts               Конфигурация сборки и manifest
```

В настройках укажите [API-ключ OpenRouter](https://openrouter.ai/settings/keys) и язык по умолчанию.
Ключ сохраняется в `browser.storage.local` этого браузера, без синхронизации между устройствами.
Пустое поле ключа при сохранении удаляет доступ к API.

В popup вставьте текст, выберите русский или английский язык и нажмите «Перевести».
Исходный язык определяется автоматически. Результат можно выделить и скопировать.
Используется фиксированная модель [`openai/gpt-6-luna`](https://openrouter.ai/openai/gpt-6-luna)
с [`reasoning.effort: "low"`](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens).
Запрос отправляется напрямую в OpenRouter только при нажатии кнопки; текст обрабатывается OpenRouter и провайдером модели.
Тексты не сохраняются. Повторное открытие popup очищает поля. Запросы выполняются в фоне с таймаутом 25 секунд.
Проверки API выполняются с подменённым fetch, без реального ключа и платных запросов.

## Перевод выделения на странице

Выделите слово или фрагмент обычного текста: справа-снизу появится кнопка перевода.
Нажмите её, чтобы получить перевод в карточке рядом с выделением. Язык берётся из настроек.
В модель передаются выделение, предложение (или предложения), в которое оно входит,
и по одному соседнему предложению с каждой стороны, если они есть.
Только выделенный фрагмент запрашивается для перевода; остальной текст служит контекстом.
При выделении одного слова ниже перевода показывается краткая справка на языке перевода:
значение в контексте, специальные термины, устойчивые выражения и игра слов,
включая составные слова и каламбуры из нескольких слов. При нехватке контекста модель должна указать неопределённость.
Перевод и справка получаются одним запросом, в отдельных полях JSON. Для фраз справка не запрашивается.
Границы предложений определяются через `Intl.Segmenter`; контекст ограничен по длине.
Ключ читает только фоновый обработчик, content script не получает его.

Карточка закрывается по Escape, кнопке × или нажатию вне неё; новый выбор сбрасывает предыдущий результат.
Выделение ограничено 12 000 символов. Первая версия работает на HTTP/HTTPS-страницах,
включая доступные фреймы, с обычным HTML-текстом. Редакторы, поля ввода, Shadow DOM, PDF,
canvas и служебные страницы браузера не поддерживаются.
После установки обновления перезагрузите уже открытые страницы, чтобы загрузился content script.

Для работы с API браузера используйте `import { browser } from 'wxt/browser'`.
Для взаимодействия с веб-страницами можно добавить `entrypoints/content.ts` через `defineContentScript` и указать нужные `matches`.
Разрешения и метаданные задаются в `wxt.config.ts`: `storage` и доступ к HTTP/HTTPS-страницам для чтения выделения и контекста.
После обновления разрешений перезагрузите расширение на странице управления расширениями.

Перед публикацией замените тестовый Firefox ID `ai-translate@example.org`, добавьте PNG-иконки в `public/icon/`
и подготовьте политику конфиденциальности. Firefox `data_collection_permissions` объявляет передачу
ключа авторизации, введённого текста и контекста страницы (`authenticationInfo`, `personalCommunications`, `websiteContent`);
при расширении функциональности обновите категории в соответствии с фактическим поведением.

Документация: [WXT](https://wxt.dev/), [Vue](https://vuejs.org/).
