# AI Translate

Расширение для Chrome и Firefox, которое переводит текст через OpenRouter с учётом контекста. Выделите слово или фрагмент на странице, нажмите появившуюся кнопку и получите перевод рядом с выделением. Для отдельных слов доступна краткая справка, а детали можно уточнить в диалоге с моделью.

Проект использует Vue 3, TypeScript и WXT на базе Vite. Сборки для обоих браузеров используют Manifest V3. Серверная часть не требуется: запросы к OpenRouter выполняются в фоновом обработчике расширения.

## Возможности

- **Перевод на странице.** Кнопка появляется справа-снизу от выделенного фрагмента; результат открывается в карточке рядом с ним.
- **Контекст перевода.** Модель получает выделение, предложение или предложения, в которые оно входит, и по одному соседнему предложению с каждой стороны. Перевод запрашивается только для выделенного фрагмента.
- **Справка о слове.** При выделении одного слова под переводом показывается значение в контексте и особенности употребления. Когда это применимо, справка объясняет специальные термины, устойчивые выражения и игру слов, включая составные слова и каламбуры из нескольких слов. Инструкция модели исключает отрицательные классификации и комментарии о невозможности классифицировать слово.
- **Уточняющий диалог.** Под переводом и справкой можно задать дополнительные вопросы. Модель учитывает исходный текст, окружающий контекст, перевод, справку и предыдущие сообщения диалога.
- **Перевод в popup.** Окно расширения позволяет вручную ввести текст и выбрать язык перевода.

Поддерживаются русский и английский языки перевода. Исходный язык определяет модель. Используется фиксированная модель `openai/gpt-6-luna` с `reasoning.effort: "low"`; выбора моделей в интерфейсе пока нет.

## Быстрый старт

Нужны Node.js 24 LTS версии 24.15+ или Node.js 22 LTS версии 22.22.2+, npm и установленный Chrome или Firefox. Минимальная версия Firefox — 140.

В папке проекта выполните:

```sh
npm ci
npm run build:all
```

`npm ci` устанавливает зависимости по `package-lock.json` и запускает `wxt prepare`, который создаёт служебные файлы и типы в `.wxt/`.

### Chrome

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `.output/chrome-mv3`.

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение**.
3. Выберите файл `.output/firefox-mv3/manifest.json`.

Такая установка в Firefox временная: дополнение удаляется после перезапуска браузера. Для обычной постоянной установки потребуется подписанный пакет.

### Постоянная установка в Zen

Zen поддерживает Firefox-расширения. Для установки вне режима разработки используйте подписанный Mozilla пакет:

1. Выполните `npm run zip:firefox`. В `.output/` появятся архив расширения `ai-translate-0.1.0-firefox.zip` и архив исходников `ai-translate-0.1.0-sources.zip`.
2. Войдите в [Mozilla Add-ons Developer Hub](https://addons.mozilla.org/developers/addon/submit/distribution).
3. Выберите **On your own** (самостоятельное распространение), чтобы получить подпись без размещения расширения в каталоге.
4. Загрузите архив расширения. На шаге предоставления исходников загрузите архив `sources`; команды сборки: `npm ci`, затем `npm run build:firefox`.
5. После завершения проверки скачайте подписанный файл `.xpi`.
6. В Zen откройте `about:addons`, нажмите шестерёнку и выберите **Установить дополнение из файла…**, затем укажите подписанный `.xpi`.

Обычный ZIP из сборки не содержит подписи Mozilla. Переименование ZIP в XPI не подписывает его.
После установки сохраните ключ OpenRouter в настройках и обновите страницы сайтов.

Для обновлений повышайте `version` в `package.json`, загружайте новую версию в ту же запись Mozilla и устанавливайте новый подписанный XPI.
Автоматические обновления для самостоятельного распространения в проекте не настроены.

Источники: [расширения Zen](https://docs.zen-browser.app/user-manual/extensions), [подпись для самостоятельного распространения](https://extensionworkshop.com/documentation/publish/submitting-an-add-on/#self-distribution).

### Настройка OpenRouter

1. Создайте [API-ключ OpenRouter](https://openrouter.ai/settings/keys).
2. Откройте popup расширения и нажмите **Настройки**.
3. Введите ключ, выберите язык по умолчанию и сохраните настройки.
4. Разрешите расширению доступ к сайтам и обновите страницу, на которой хотите переводить текст.

Для запросов нужны доступ к выбранной модели и достаточный баланс OpenRouter. Чтобы удалить сохранённый ключ, очистите его поле в настройках и нажмите **Сохранить**.

## Использование

### Перевод выделения

Выделите текст мышью или клавиатурой и нажмите кнопку перевода возле выделения. Карточка покажет перевод на язык из настроек. При выделении одного слова ниже появится блок **О слове**. Результат можно выделить и скопировать.

Карточка закрывается по **Escape**, кнопке **×** или нажатию вне неё. Новое выделение сбрасывает предыдущий перевод и диалог.

### Уточнение перевода

Введите вопрос в поле под переводом и справкой. Нажмите кнопку отправки или **Enter**; **Shift+Enter** добавляет новую строку. После первого вопроса ниже поля появляется история сообщений.

Каждый запрос включает контекст выделения, первоначальный перевод и справку, а также все предыдущие успешные сообщения этого диалога. При ошибке вопрос возвращается в поле: его можно исправить или отправить повторно.

Диалог хранится в памяти карточки и сбрасывается при закрытии, новом выделении, обновлении страницы или переходе на другую страницу.

### Перевод в popup

Нажмите значок расширения в панели браузера, вставьте текст, выберите язык и нажмите **Перевести**. Этот режим переводит только введённый текст; контекст страницы, справка о слове и диалог здесь не используются. Выбор языка в popup действует для текущего перевода; язык по умолчанию меняется в настройках.

## Разработка

```sh
npm run dev          # Chrome
npm run dev:firefox  # Firefox
```

WXT обновляет сборку при изменении файлов и пытается открыть выбранный браузер с расширением. Если появляется сообщение `Load ... as an unpacked extension manually`, загрузите расширение вручную, используя сборку разработки:

| Браузер | Сборка разработки | Обычная сборка |
| --- | --- | --- |
| Chrome | `.output/chrome-mv3-dev/` | `.output/chrome-mv3/` |
| Firefox | `.output/firefox-mv3-dev/manifest.json` | `.output/firefox-mv3/manifest.json` |

Оставьте команду разработки запущенной. После изменения manifest, разрешений или обновления расширения перезагрузите расширение и уже открытые веб-страницы.

Если WXT не находит браузер, путь к исполняемому файлу можно указать в локальном `web-ext.config.ts`. Этот файл исключён из Git. См. [настройку запуска браузера в WXT](https://wxt.dev/guide/essentials/config/browser-startup).

### Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Разработка в Chrome |
| `npm run dev:firefox` | Разработка в Firefox |
| `npm run typecheck` | Проверка TypeScript и Vue-компонентов |
| `npm test` | Тесты API, контекста выделения и протокола сообщений |
| `npm run build` | Сборка для Chrome |
| `npm run build:firefox` | Сборка для Firefox |
| `npm run build:all` | Сборка для обоих браузеров |
| `npm run zip` | Подготовка архива для Chrome |
| `npm run zip:firefox` | Подготовка архивов расширения и исходников для Firefox |

Проверка перед коммитом:

```sh
npm run typecheck
npm test
npm run build:all
```

Тесты используют Node.js test runner и jsdom. Ответы OpenRouter подменяются: реальный ключ и платные запросы не нужны. Тесты не проверяют качество ответов живой модели.

## Структура проекта

```text
assets/
  main.css                       Общие стили popup и настроек
entrypoints/
  background.ts                  Обработка сообщений и запросов к OpenRouter
  popup/                         Ручной перевод текста
  options/                       API-ключ и язык по умолчанию
  selection.content/
    index.ts                     События выделения, позиционирование, Shadow DOM
    App.vue                      Кнопка и карточка перевода
    Dialogue.vue                 Временный диалог уточнений
    style.css                    Стили интерфейса на странице
utils/
  settings.ts                    Чтение и сохранение настроек
  selection.ts                   Чтение выделения и окружающего текста из DOM
  translation-context.ts         Выделение соседних предложений
  single-word.ts                 Определение одиночного слова
  translation-messages.ts        Типы и проверка сообщений расширения
  openrouter.ts                  Общий API-клиент и запрос перевода
  followup.ts                    Формирование запроса с историей диалога
tests/                           Тесты с подменённым API и DOM-фикстурами
wxt.config.ts                    Метаданные, разрешения и конфигурация сборки
```

Content script читает выделение и показывает Vue-интерфейс в Shadow DOM, чтобы стили сайта не влияли на карточку. Запросы передаются через `browser.runtime.sendMessage` фоновому обработчику, который читает ключ и обращается к OpenRouter. API-ключ не передаётся в content script.

## Данные и разрешения

API-ключ и язык по умолчанию сохраняются в `browser.storage.local`, без синхронизации между устройствами. Тексты, переводы и сообщения диалога расширение не сохраняет в постоянное хранилище.

При выделении текста запрос к модели не отправляется. После нажатия кнопки перевода в OpenRouter передаются выбранный фрагмент и извлечённый контекст; при отправке уточнения — также перевод, справка и история диалога. Данные обрабатываются OpenRouter и провайдером модели.

В manifest объявлены:

- `storage` — сохранение ключа и настроек;
- доступ к HTTP/HTTPS-сайтам — чтение выделения, контекста и показ интерфейса, а также обращение к OpenRouter;
- в Firefox — категории передачи данных `authenticationInfo`, `personalCommunications` и `websiteContent`.

## Ограничения

- Перевод выделения работает с обычным HTML-текстом на HTTP/HTTPS-страницах и в доступных фреймах.
- Поля ввода, редактируемые области, выделение внутри Shadow DOM, текст в canvas, PDF и служебные страницы браузера не поддерживаются.
- Выделение и текст в popup ограничены 12 000 символами.
- Вопрос в диалоге ограничен 2 000 символами; один диалог — 19 вопросами. Фоновый обработчик дополнительно ограничивает суммарный объём истории.
- Контекст определяется через `Intl.Segmenter` в пределах выбранной области страницы. Соседние предложения могут отсутствовать; длинный контекст обрезается.
- Таймаут запроса к OpenRouter — 25 секунд. Ошибки ключа, баланса, лимитов, сети и некорректные ответы показываются в интерфейсе.
- Перевод, справка и ответы на уточнения генерируются моделью; их качество зависит от исходного текста и доступного контекста.

## Решение частых проблем

**Кнопка возле выделения не появляется.** Проверьте доступ расширения к сайту и обновите страницу после установки или перезагрузки расширения. Убедитесь, что выделяете обычный текст, а не содержимое поля ввода, редактора или PDF.

**OpenRouter отклоняет запрос.** Проверьте сохранённый ключ, баланс и доступ к `openai/gpt-6-luna`. При превышении лимита повторите запрос позже.

**После изменения кода виден старый интерфейс.** Проверьте, что загружена нужная папка сборки. Перезагрузите расширение в браузере и обновите вкладку сайта.

## Публикация

В `wxt.config.ts` задан постоянный Firefox ID `{ff7f419e-0556-4c74-96ff-26dffa0ac40d}`. Сохраняйте его при выпуске обновлений после первой подписи.
Перед публикацией в каталоге добавьте иконки, подготовьте политику конфиденциальности и материалы для магазина расширений. При изменении обработки данных обновите разрешения и категории передачи данных.

Архивы создаются командами `npm run zip` и `npm run zip:firefox` в `.output/`. Эти команды подготавливают файлы, но не публикуют расширение в магазинах.
